# Flash Trade 暂停管理脚本

## 📋 功能说明

这个脚本实现了完整的暂停管理流程：

1. **清理挂单** - 强制清理所有现有挂单
2. **验证清理** - 确认挂单已被清理
3. **设置暂停** - 暂停账号交易，等待手动恢复
4. **批量操作** - 支持多节点并发操作

## 🚀 快速开始

### 1. 构建程序

**Windows:**
```bash
build_pause_manager.bat
```

**Linux/macOS:**
```bash
chmod +x build_pause_manager.sh
./build_pause_manager.sh
```

### 2. 配置文件

修改 `config.json` 文件，填入正确的节点信息：

```json
[
  {
    "id": "account_001",
    "name": "测试账号1", 
    "ip": "127.0.0.1",
    "csrftoken": "your_csrf_token_1",
    "cookie": "your_cookie_1"
  }
]
```

### 3. 运行程序

**Windows:**
```bash
pause_manager_windows_amd64.exe
```

**Linux:**
```bash
./pause_manager_linux_amd64
```

**macOS:**
```bash
./pause_manager_mac_arm64  # ARM版本
./pause_manager_mac_amd64  # Intel版本
```

## 📖 使用流程

### 运行时交互

1. **输入暂停时长**
   ```
   请输入暂停时长（小时，默认24小时）: 12
   ```

2. **输入暂停原因**
   ```
   请输入暂停原因（默认: manual_maintenance）: 系统维护
   ```

3. **确认执行**
   ```
   确认执行暂停管理操作? (y/N): y
   ```

### 执行过程

程序会对每个节点执行以下步骤：

1. **🧹 清理挂单** - 调用 `/cleanup-orders` 接口强制清理所有挂单
2. **⏳ 等待生效** - 等待3秒确保清理生效
3. **🔍 验证清理** - 检查挂单是否已清理完成
4. **⏸️ 设置暂停** - 调用 `/pause-status` 接口设置账号暂停

## 🔧 手动恢复方法

### 方法1: HTTP API

```bash
# 恢复指定账号
curl -X DELETE "http://节点IP:8080/pause-status?account_id=账号ID"

# 示例
curl -X DELETE "http://127.0.0.1:8080/pause-status?account_id=account_001"
```

### 方法2: Web界面

访问 Flash Trade Web 管理界面，在暂停状态页面手动恢复。

### 方法3: 强制恢复所有暂停

```bash
curl -X POST "http://节点IP:8080/resume"
```

## ⚠️ 注意事项

1. **运行环境**
   - 确保目标服务器的 Flash Trade 服务正在运行（端口8080）
   - 确保网络连接正常
   - 建议在维护时间窗口执行

2. **配置文件**
   - `csrftoken` 和 `cookie` 必须是有效的认证信息
   - `ip` 地址必须可访问
   - `id` 必须与 Flash Trade 中的账号ID匹配

3. **安全建议**
   - 不要在生产环境中硬编码敏感信息
   - 定期更新认证令牌
   - 在执行前备份重要数据

4. **故障排除**
   - 如果清理挂单失败，可能是网络问题或认证失效
   - 如果暂停设置失败，检查账号ID是否正确
   - 查看 Flash Trade 服务日志获取详细错误信息

## 🔗 相关接口

- `POST /cleanup-orders` - 清理挂单
- `POST /pause-status` - 设置暂停
- `GET /pause-status` - 查询暂停状态
- `DELETE /pause-status` - 清除暂停状态
- `POST /resume` - 强制恢复所有暂停
