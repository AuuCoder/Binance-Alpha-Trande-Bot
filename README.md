# Alpha Bot

一个高效、智能的自动化加密货币交易机器人，专为快速交易和风险控制而设计。

### 🚀 核心特性

#### 🔥 Flash Trade 核心引擎

- **超快速交易**: 毫秒级下单响应，抢占市场先机
- **智能递减策略**: 万 1 → 万 6 → 万 11 → ... → 百 10 的渐进式降价
- **多层风险控制**: 智能止损、磨损限制、异步监控
- **防卡单优化**: 超时时间统一、订单状态同步、竞态条件优化
- **速度模式选择**: 快速/正常/慢速三种模式，适应不同交易需求

#### 🎯 交易策略

- **市场价策略**: 实时价格获取，精准定价
- **递减重试**: 21 步精细化递减，最大化成交概率
- **挂单模式**: 达到磨损限制时智能挂单等待成交
- **异步处理**: 挂单异步监控，不阻塞新交易
- **WebSocket 价格获取**: 使用长连接实时获取价格数据，减少 API 调用频率

#### 🛡️ 风险管理

- **磨损控制**: 最大磨损限制 10% (百 10)
- **智能止损**: 市场异常时快速止损
- **资金管理**: 动态余额检查，防止过度交易
- **网络容错**: 断网重连、API 限频处理
- **极端行情检测**: 自动检测市场异常波动，暂停交易保护资金安全
- **API 限频优化**: 智能调整 API 请求频率，避免触发交易所风控

#### 📊 监控统计

- **实时统计**: 交易量、盈亏、成功率实时监控
- **账户管理**: 多账户支持，独立统计
- **交易日志**: 详细交易记录，便于分析优化
- **市场状态监控**: 实时监控市场状况，自动应对异常波动
- **价格缓存机制**: 缓存价格数据，减少重复 API 调用

#### 🔄 自动化功能

- **自动暂停恢复**: 检测到极端行情自动暂停，市场稳定后自动恢复
- **自动清理机制**: 定期清理过期订单和代币残留
- **智能重试机制**: 交易失败自动重试，确保交易完成
- **批量任务处理**: 支持批量下发交易任务和暂停/恢复操作
- **多链支持**: 支持 BSC、Solana 等多条区块链

### 🌊 极端行情检测与自动暂停

#### 核心功能

- **实时行情监控**: 通过 WebSocket 订阅 K 线数据，实时监控代币价格变动
- **多维度异常检测**: 同时监控 24 小时涨跌幅和短时间内的价格波动
- **自动暂停交易**: 检测到极端行情自动暂停所有相关账户交易
- **智能清理机制**: 暂停时自动清理挂单和代币残留，保护资金安全
- **自动恢复交易**: 市场恢复稳定后，自动恢复被暂停的账户交易

#### 检测指标

- **暴跌检测**: 当 24 小时涨跌幅低于设定阈值时，判定为极端下跌（默认 -15%）
- **波动检测**: 当短时间内价格波动超过设定阈值时，判定为极端波动（默认 10%）
- **稳定判定**: 当市场波动小于稳定阈值且持续时间超过设定值时，判定为稳定（默认 5%，持续 15 分钟）

#### 配置参数

| 参数名              | 说明                   | 默认值 | 小额交易建议值 |
| ------------------- | ---------------------- | ------ | -------------- |
| enabled             | 是否启用极端行情检测   | true   | -              |
| drop_threshold      | 极端下跌阈值（百分比） | -15.0  | -20% 至 -25%   |
| volatile_threshold  | 极端波动阈值（百分比） | 10.0   | 15% 至 20%     |
| auto_pause          | 是否自动暂停           | true   | -              |
| pause_duration      | 暂停持续时间（分钟）   | 30     | 15-20 分钟     |
| cleanup_orders      | 是否清理挂单           | true   | -              |
| cleanup_tokens      | 是否清理代币残留       | true   | -              |
| auto_resume_enabled | 是否自动恢复           | true   | -              |
| stability_threshold | 稳定阈值（百分比）     | 5.0    | 8% 左右        |
| stability_duration  | 稳定持续时间（分钟）   | 15     | -              |

#### 工作流程

1. **实时监控**: 系统通过 WebSocket 长连接实时接收 K 线和交易数据
2. **异常检测**: 根据配置的阈值检测价格暴跌或剧烈波动
3. **触发暂停**: 检测到极端行情时，记录暂停状态并标记受影响账户
4. **清理操作**: 暂停后自动取消所有挂单，并可选择清理代币残留
5. **稳定监控**: 定期检查暂停的代币市场状态，判断是否恢复稳定
6. **自动恢复**: 当市场波动小于稳定阈值且持续时间超过设定值时，恢复交易

#### API 接口

- **获取配置**: `GET /api/extreme-market-config` - 获取当前极端行情配置和暂停状态
- **更新配置**: `POST /api/extreme-market-config` - 更新极端行情检测配置参数

### 🏗️ 系统架构

```
│   Flash Trade       │◄──►│  Alpha AutoSell      │◄──►│   Web Dashboard      │
│   (端口 8080)        │    │   (端口 8081)        │    │   (静态网页)          │
│                     │    │                     │    │                     │
│ • 核心交易引擎        │    │ • 账户管理           │    │ • 监控面板           │
│ • 递减策略执行        │    │ • 自动循环           │    │ • 配置管理           │
│ • 风险控制           │    │ • 统计上报           │    │ • 数据可视化         │
│ • API 接口           │    │ • 远程控制           │    │ • 用户界面           │
└─────────────────────┘    └──────────────────────┘    └──────────────────────┘
           │                           │                           │
           ▼                           ▼                           ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                          🗄️ Redis 统一数据存储                              │
│             (账户信息、交易统计、配置管理、状态同步)                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 🎯 交易流程详解

#### 1. 买入阶段

```
价格获取 → 资金检查 → 下单 → 成交确认 → 启动卖出监控
```

#### 2. 卖出策略

```
市场价尝试 → 递减重试 → 挂单等待 → 异步监控 → 强制处理
```

#### 3. 递减步骤

```
万1(0.01%) → 万6(0.06%) → 万11(0.11%) → ... → 百10(10%)
```

#### 4. 风控机制

```
智能止损 → 磨损控制 → 异步处理 → 兜底清理 → 极端行情检测
```
